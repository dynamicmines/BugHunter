# BugHunter

Тренажёр поиска ошибок в коде. Flutter, Material 3. Экраны сделаны по Figma-файлу BugHunter (20 экранов, цвета и размеры сняты с экспорта).

## Запуск

```
cd ~/Desktop/bughunter_full
flutter create . --project-name bughunter --platforms=android,ios,web
flutter pub get          # обязательно: появились шрифты Inter и JetBrains Mono
flutter run -d chrome    # в браузере (DevTools, режим телефона)
flutter run -d <id>      # телефон или эмулятор, список: flutter devices
flutter test
```

`flutter create .` один раз создаёт android, ios, web и не трогает lib/, test/, pubspec.yaml.

Важно: код написан без Flutter SDK, он не компилировался. Если `flutter run` или `flutter analyze` покажет ошибки, пришлите вывод, исправим.

## Как устроено приложение

Язык → уровни → задачи. На каждом уровне сверху «Разбор темы» (короткая теория с примерами кода), ниже список задач. Задача открывается после решения предыдущей, уровень после прохождения предыдущего.

Два типа задач: «Найди ошибку» (нажать на строку кода) и «Вопрос» (выбрать вариант). После ответа экран результата: «Было / Стало», объяснение и очки, а при ошибке подсказка и повторная попытка.

Очки: лёгкая 10, средняя 20, сложная 30. Каждая ошибка до верного ответа снимает 5, но не меньше 5. Повторное решение очков не даёт. Серия: дни подряд, когда решена хотя бы одна задача. Точность: решено / (решено + ошибки).

## Экраны

Из Figma: заставка, главная (новичок, с прогрессом, всё пройдено, нет соединения, скелетон), уровни, обзор уровня, задача, результат (верно и ошибка), профиль, вход, регистрация, отправка кода, ввод кода (6 ячеек), забыли пароль, новый пароль, пароль изменён.

Добавлено, потому что в Figma этого нет: настройки (шестерёнка в профиле), смена пароля, разбор темы, выбор языка (значок перевода на экране уровней и в настройках).

Экран 10 «Проверка · нет интернета» не используется: ответы проверяются на устройстве. Экраны 02 (скелетон) и 09 (нет соединения) включаются, только когда задан `kContentUrl` и идёт обновление контента.

## Авторизация

Регистрация → код из письма (6 цифр, 10 минут, 5 попыток, повтор через 30 с) → вход. Сброс пароля: почта → код → новый пароль. Вход с неподтверждённой почтой снова выдаёт код.

Писем нет, сервера нет. Пока `kDemoMail = true` в `lib/core/constants.dart`, код показывается на экране ввода в жёлтой плашке. Для настоящей почты замените тело `AuthState._deliver` вызовом вашего API (или перейдите на Firebase Auth) и поставьте `kDemoMail = false`.

Пароль хранится как соль и многократный SHA-256. После 5 неверных паролей вход блокируется на 30 секунд. Ошибка входа общая («Неверная почта или пароль»).

## Как добавить задачи и уроки

Контент лежит в `assets/content/content.json`:

```
{ "version": 2,
  "languages": [ { "id", "title", "description",
    "levels": [ { "id", "title", "subtitle", "intro",
      "theory": [ {"type": "text"|"code", "text": "..."} ],
      "tasks": [ { "id", "type": "find"|"choice", "title", "description",
                   "code", "bugLine", "fix",            // для find (bugLine с нуля)
                   "options", "answer",                  // для choice
                   "hint", "retryHint", "explanation", "difficulty": 0..2, "minutes" } ] } ] } ] }
```

Добавьте задачу или уровень, увеличьте `version`, пересоберите приложение. Без пересборки: выложите файл по прямой ссылке (например, GitHub Raw), вставьте её в `kContentUrl`, затем «Настройки → Обновить задания и уроки» или потяните главную вниз. Скачивается только версия больше текущей, она кэшируется и работает без интернета. Тест `flutter test` проверяет целостность файла.

Сейчас: 3 языка (Python, JavaScript, Dart), 11 уровней, 56 задач.

## Структура

```
lib/main.dart              запуск, провайдеры
lib/core/                  theme (токены Figma), widgets, validators, constants, util
lib/models/                AppUser, Language/Level/Task, TaskResult/CheckOutcome
lib/data/                  content_repository (чтение JSON + кэш)
lib/state/                 auth_state, content_state, progress_state
lib/screens/               все экраны
assets/content/content.json  задачи и теория
assets/fonts/              Inter, JetBrains Mono
```

## Дальше

Данные лежат на устройстве (shared_preferences). Для настоящих писем и синхронизации между устройствами замените AuthState на Firebase Auth, а результаты храните в Firestore. Экраны работают только с AuthState, ContentState и ProgressState, поэтому не изменятся.
